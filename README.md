Soy desarrollador full stack enfocado en construir **software de operación real**: sistemas de cobro de peaje, APIs empresariales, aplicaciones de escritorio con integración de hardware y sitios web corporativos.

- 🔌 Me gusta integrar software con hardware: impresoras térmicas, puertos serie, Modbus.

- 🌎 Construyo sitios bilingües (español / inglés).

## 🚀 Proyectos destacados

### 🛣️ EKKOTOLL — Sistema Desktop de Peaje
[`peaje-desktop`](https://github.com/EDUARDJ1001/peaje-desktop)

Aplicación de escritorio para operar casetas de peaje, usada por operadores, supervisores y administradores.

- **Electron + React (Vite)** con Material UI, Tailwind y Recharts.
- Base de datos **local (SQLite)** con **sincronización** a bases en línea (SQL Server / PostgreSQL).
- Integración de hardware: **impresoras térmicas**, **puerto serie** y **Modbus**.
- Tiempo real con **Socket.IO**, reportes en **PDF y Excel**, actualizaciones automáticas con `electron-updater`.
- Manuales de usuario para operador, supervisor y administrador.

`Electron` `React` `Node.js` `SQLite` `SQL Server` `PostgreSQL` `Socket.IO`

---

### 🦩 Pelican Pass — API y Web
[`pelican-pass-api`](https://github.com/zarcolini/pelican-pass-api) · `pelican-pass-web`

Plataforma de peaje electrónico con tags para clientes.

- **API REST** en Node.js + Express con autenticación **JWT** y login social (**Google / Facebook** vía Passport).
- Seguridad con Helmet, rate limiting y validación de datos; documentación con **Swagger**.
- Módulos CRUD, gestión de contratos, vehículos y tags.
- **Sitio web** en React + Vite + Tailwind con animaciones en **Three.js**, tarifas, cobertura y registro de usuarios.

`Node.js` `Express` `Azure SQL` `PostgreSQL` `React` `Three.js` `Tailwind`

---

### 🔧 AutoGestion — Gestión de Taller Automotriz
[`AutoGestion`](https://github.com/EDUARDJ1001/AutoGestion)

Sistema web para la administración de un taller mecánico.

- Clientes, vehículos, visitas, servicios con precios negociados, inventario, dashboard y panel del mecánico.
- Usuarios y roles con **JWT**, migraciones SQL y API documentada con **Swagger**.
- Despliegue en **Vercel** con almacenamiento de archivos en Vercel Blob.

`Node.js` `Express` `PostgreSQL` `React` `Vite` `Vercel`
